# Blockbase for VS Code

Browse your local [Blockbase](https://github.com/taylorsegell/blockbase) component catalog from VS Code, Cursor, and other editors that install from Open VSX.

<!-- Screenshot placeholder: catalog panel (media/screenshot-panel.png) -->

## Requirements

- Blockbase installed and a catalog at `~/.blocks` (see the main README).

## Features

- **Catalog view** in the activity bar.
- **Blockbase: Refresh** reloads the catalog.
- **Blockbase: Open Catalog Panel** opens the catalog in an editor panel.

## Install

- VS Code: search for "Blockbase" (publisher `arkitect`) in the Extensions view.
- Cursor and other Open VSX editors: search for "Blockbase" in the Extensions view.
